# Тиффани — семейное кафе

Первая версия адаптивного сайта семейного кафе на React + Vite.

## Что внутри

- Главная страница
- Адаптивная шапка и мобильное меню
- Hero-блок
- Блок «О нас»
- Категории меню
- Карточки блюд
- Анимации и hover-эффекты
- Контакты и подвал
- Адаптивная версия для телефонов

## Запуск

Нужен Node.js 18+.

1. Распакуйте проект.
2. Откройте терминал в папке проекта.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Production-сборка

```bash
npm run build
```

Для проверки production-сборки:

```bash
npm run preview
```

## Где менять меню

Все блюда находятся в:

`src/data/menu.js`

Там можно менять название, описание, вес, цену, категорию и фотографию.

## Важно

Фотографии в первой версии загружаются с Unsplash. Перед публикацией сайта лучше заменить их на собственные фотографии кафе/блюд или изображения с подходящей лицензией.

Контактные данные и адрес в Footer — демонстрационные и должны быть заменены на реальные.
